## Layar yang ada di aplikasi baru tetapi tidak tertangkap di sini

- Distribusi Debitur dengan bawahan berisi data (akun uji ini tidak punya bawahan di data lokal); redistribusi dan Generate Excel agen visit.
- Monitoring Recovery, Memo (Hapus Buku, AYDA, SKPM, Restrukturisasi), Janji Debitur dengan hasil, dialog Peringatan, ubah password wajib (`/change-password`).
- Layar modul Reporting di modul 70 (MIS): Daily Tracking, Leading Edge, Lag Delinquency, Flow Rate, dan lain-lain. Butuh DB modul 70.
- Layar yang masih memakai data kosong pada salinan lokal (Monitoring Debitur kosong untuk akun ini).

## Cara mengulang

Jalankan aplikasi (`dotnet run --project src/Panin.Web`) lalu skrip penjelajah menu Playwright; daftar menu diambil otomatis dari sidebar, jadi layar baru ikut tertangkap.
